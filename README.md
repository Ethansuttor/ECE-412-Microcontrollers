# Dual-Factor Hardware Security System

ATmega328PB-based security system written in bare-metal C using Microchip Studio.

Implements custom 30ms software debouncing, interrupt service routines (ISRs) for state management, UART communication, and PWM servo actuation via Timer1 Fast PWM to drive a servo lock mechanism.

**Course:** ECE 412 — Microcontrollers, University of Louisville (Spring 2025)
